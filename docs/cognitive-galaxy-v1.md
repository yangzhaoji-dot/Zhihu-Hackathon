# Cognitive Galaxy v1 — 二维认知星图

基于 `resonance-scroll-v1` 的独立前端路线。原世界页面与数据服务保留；新入口不再加载原 Three.js 星系引擎。

## 本轮范围

世界观序章（可跳过/暂停/重播）→ 首页搜索与推荐 → 问题星系全景 → 思考星群 → 观点聚焦 → 登陆入口。

点击「登陆星球」明确显示阶段终点，不跳到未经重新设计的旧地图。星球表面、碰撞融合、社交、点赞和共鸣系统不在本轮新增范围。

## 运行与入口

```sh
bun install --frozen-lockfile
bun dev
```

- `/`：主页与首次访问序章。
- `/galaxy/demo-luoci`：无需外部 API 的演示星系。
- `/galaxy/demo-luoci?cluster=health`：星群。
- `/galaxy/demo-luoci?cluster=health&opinion=demo-health-0`：观点聚焦。

推荐中的演示入口可离线使用；其余推荐与搜索复用 `/api/opinion/build`。搜索返回多个候选问题时，需要用户选择。失败不会悄悄替换成裸辞演示数据。

## 美术与导航原则

2D SVG + CSS 参数化天体、星雾、纹理、星尘；Framer Motion 承担 viewBox 语义缩放与序章转场。无新增渲染依赖、外部贴图或模型资产。

全景以问题核心为中心，所有已提取真人观点按思考方向成群。点击星群后保持同一批节点与布局，仅改变观察尺度。点击星球时再放大主体并显示摘要、已有来源和阶段边界。始终可通过面包屑、返回控件、Escape 或浏览器后退离开当前层级。

背景星尘不可交互，不能被当作观点。颜色暂时只表示思考方向；亮度主要用于交互焦点。正式数据中大小按已关联来源数量缩放，不作正确性、支持率或证据强度评分。星群内部距离目前是稳定的避碰排布，不宣称具有精确的语义距离含义。

手机提供与星图等价的星群/观点按钮，避免依赖 hover 或微小的 SVG 点击区域。尊重 reduced-motion，不强制播放开场；需要时可手动重播静态分幕版本。

## 数据边界（重要）

演示包含 48 条人工编写的示例观点、6 个预设方向，页面持续标注「演示数据」。示例没有伪造来源、答主、赞数或证据；球体大小仅用于视觉演示。

真实检索继续使用现有知乎检索与观点构建服务。本轮新增的方向分类是基于观点文本的可解释关键词降级方案，**不是新训练模型或 AI 聚类**。界面明确说明这一点，不能用 `camp` 的赞成/反对阵营冒充思考方向。未来可替换 `classify` 或向 `buildGalaxy` 提供模型生成的主方向映射。

只展示本次检索中的观点，不宣称收录知乎全部讨论；不会为了宇宙密度复制实际观点。AI 推演、topic、station、user 节点不伪装为真人观点星球，暂以数量说明未纳入。

真实星系缓存于当前浏览器会话（上限 5 份），不是公开持久分享。刷新时优先恢复缓存，缺失则按 ID 请求现有服务；服务返回其他问题的默认图时会拒绝显示，提示重新搜索。没有新增私有数据服务或密钥。

## 验证

```sh
bun test scripts/cognitive-galaxy.test.ts
bun run lint
bun run build
```

`.github/workflows/cognitive-galaxy-check.yml` 为此分支运行以上检查，再用隔离安装的 Playwright 检查导航、刷新、键盘、移动布局、错误状态和可跳过序章，保存桌面/手机截图到 `cognitive-galaxy-preview` artifact。

浏览器测试中的搜索错误路径使用 mock，不等于真实知乎凭据和服务已通过验收。真实搜索必须在具备原项目环境配置的部署中再次验收。当前未针对上千节点做性能保证。

## 文件分工

- `src/app/page.tsx`：首页、候选问题选择与检索取消/超时。
- `src/app/galaxy/[questionId]/page.tsx`：可直接访问的星系路由与尺度导航。
- `src/components/cognitive-galaxy/`：美术、序章、星图与聚焦面板。
- `src/lib/cognitive-galaxy/`：布局、方向分类、明确标注的示例数据和会话缓存。
- `src/lib/api/cognitive-galaxy.ts`：复用现有鉴权/语言请求封装的类型化接口。
- `src/i18n/locales/galaxy.*.json`：中英文界面文案；不改写原始中文观点内容。

下一轮应先看实际画面再决定美术调整，不继续向旧 runtime 添加补丁层。
