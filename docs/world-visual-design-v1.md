# 分岔之城 Visual Design v1

> 状态：视觉方向锁定版。服务于 `scene-environment-first-v1` 分支。
> 目标：把当前环境优先原型，从“CSS 物件散落在地图上”升级为“具有叙事氛围、空间层次和统一视觉语言的可探索世界”。

## 0. 一句话方向

**叙事绘本式 2.5D 世界：低饱和旧城 + 冷雾 + 局部暖光 + 无人环境叙事 + 少量超现实空间关系。**

产品不是把观点画成按钮，而是让用户产生“这里为什么会这样？”的疑问，再由看山把环境现象还原到观点、来源、条件与未知。

---

## 1. 视觉参考系：各学什么

### Disco Elysium —— 学“质感与城市情绪”

我们要学：
- 手绘/油画感纹理，而不是干净矢量边缘；
- 旧城、积灰、雨痕、纸张、锈迹带来的时间感；
- 冷环境中少量琥珀暖光作为视觉锚点；
- UI 和环境气质保持一致，不像外挂网页面板。

我们不学：
- 过于阴郁、成人化的压迫气质；
- 高密度文字和复杂人物戏剧。

### Monument Valley —— 学“构图与路径可读性”

我们要学：
- 一眼能看懂主路径、分支和层级；
- 建筑轮廓简洁、空间关系明确；
- 地形可以带一点超现实，但交互逻辑必须清晰。

我们不学：
- 纯几何、纯糖果色；
- 把视觉重点放在空间谜题本身。

### COCOON —— 学“模块化与交互物可读性”

我们要学：
- 每个可交互装置有清晰轮廓和状态；
- 少量对象也能组成完整玩法；
- 场景资产可以模块化组合，而不是每个世界重画整张图。

我们不学：
- 过度科幻/机械；
- 过于干净的低多边形质感。

### SEASON: A letter to the future —— 学“留白与安静”

我们要学：
- 大片安静区域让用户愿意停下来观察；
- 遗迹、轨道、远景自然产生故事感；
- 柔和天空与自然元素缓冲城市压迫感。

我们不学：
- 大尺度开放世界；
- 过多自然风景导致观点结构难以辨认。

## 2. 最终渲染路线

### 不做

- 继续用 CSS 线条和矩形硬画最终场景；
- 直接把一整张 AI 概念图当背景；
- 为了“高级”临时切到完整实时 3D。

### 做

采用 **预渲染/手绘背景 + 分层 2.5D 资产 + 动态效果**：

1. **Background**：天空、远山、远方城市、不可到达建筑；
2. **Ground**：主岛体、道路、轨道、台阶、桥面；
3. **Architecture**：车站、办公室、工坊、档案室等中大型模块；
4. **Interactive Props**：离职箱、账本、工作台、时刻表、闸机等独立 PNG/WebP；
5. **FX**：雾、暖灯、纸张、灰尘、光束、微粒；
6. **Occlusion**：必要的前景墙体/栏杆单独分层，让玩家可以从后面经过。

这样可以保持风格 2 的绘本质感，同时保留真正的交互、遮挡、状态变化和复用能力。

## 3. 镜头与画面构图

### 镜头

- 斜俯视 2.5D；
- 近似固定相机，不允许自由旋转；
- 用户移动时只做平滑跟随；
- 一屏能看到约 30%–45% 世界；
- 进入新区域时允许极轻微推镜/重新构图，但不做复杂电影运镜。

### 整体地图结构

```text
                    [远方机会站 / 时刻表]
                         暖金色远景
                              ↑
                    ~~~~~ 长期结果迷雾 ~~~~~

        [离场街区]  ←──  [中央换乘站]  ──→  [缓冲街区]
        冷 / 红暗          暖光核心            暖黄 / 绿灰
        破办公楼           钟塔/轨道            工坊/账本
              \                |                /
               \          [条件闸机]           /
                \              |              /
                 └────── [档案与仲裁区] ──────┘
                         冷暗 / 绿灯
```

### 构图原则

- **中央换乘站必须是第一视觉中心**：用户一落地就知道“这里是选择的交汇处”；
- 左右两区形成明显情绪对比，但不能简单做成“坏 vs 好”；
- 远方机会站始终若隐若现，制造“未来存在，但不可直接抵达”的感觉；
- 档案区在下层或地下，产生“向下挖证据”的空间隐喻；
- 雾不是装饰，要真正遮挡视野/道路；
- 不显示“止损派 / 稳健派 / 维权派”大标签，区域意义由环境读出来。

## 4. 五个关键区域

## A. 中央换乘站 — 选择发生的地方

**情绪**：安静、稳定、略有仪式感。

**视觉锚点**：
- 老钟；
- 轨道分叉；
- 暖色玻璃顶；
- 条件闸机；
- 去往不同区域的半亮路灯。

**环境语义**：这里不给答案，只告诉用户“存在多条路线”。

**主色**：灰蓝 + 暖琥珀。

---

## B. 离场街区 — “继续留下是否已经在伤害我？”

**情绪**：压抑、疲惫、停滞，但不是恐怖。

**视觉元素**：
- 熄灯或只剩红色应急灯的办公楼；
- 堆积文件；
- 空工位；
- 离职申请箱；
- 停摆电梯；
- 断续的广告牌/提示灯。

**环境动态**：
- 纸张偶尔被风吹起；
- 荧光灯轻微闪烁；
- 远处仍可听见机器低鸣，表示工作并未停止。

**注意**：不要做成“辞职就是解放”；这里表达的是压力与止损条件，而不是价值判断。

---

## C. 缓冲街区 — “能否先准备，再决定？”

**情绪**：温暖、可操作、有秩序，但不能像成功学乐园。

**视觉元素**：
- 还亮着灯的小工坊；
- 现金流账本台；
- 在职试验工作台；
- 一块不断更新的招聘/机会屏；
- 小型储物柜、书、工具、植物。

**环境动态**：
- 屏幕缓慢刷新；
- 台灯暖光；
- 很轻的机械/键盘音效。

**视觉对比**：比左侧明亮，但依然是旧城材料，不突然切成崭新科技园。

---

## D. 档案与仲裁区 — “别只听观点，去看依据”

**情绪**：安静、理性、旧资料室感。

**视觉元素**：
- 档案柜；
- 文件堆；
- 绿色台灯；
- 放大镜/标注；
- 仲裁记录柜；
- 一张空长椅。

**空间设计**：位于较低层，需要从中央区域沿台阶/坡道下去。

**交互**：这里最适合承载“查看原回答 / 来源 / 时间 / 作者 / 支持度”的深层资料。

---

## E. 长期结果迷雾 / 远方机会站 — “未来并不可见”

**情绪**：神秘、希望与不确定同时存在。

**视觉元素**：
- 大面积低速流动的雾；
- 被雾吞掉的轨道；
- 远处暖金色的机会站；
- 一块只有部分班次亮起的时刻表；
- 若隐若现的桥梁结构。

**重要规则**：远方不能被画成天堂。它只是“可能性存在”。

---

## 5. 光影规则

### 整体时间

统一设为 **蓝调时刻 / 傍晚进入夜晚**。

原因：
- 冷环境 + 暖灯最容易形成风格 2 的情绪；
- 灯光天然成为交互引导；
- 既有疲惫感，又保留远方希望。

### 色彩关系

- 天空 / 雾：灰蓝、蓝紫；
- 建筑主体：低饱和灰褐、冷灰绿；
- 交互暖光：琥珀、旧黄；
- 危险/压力提示：暗红，只少量使用；
- 档案区：冷绿台灯作为独立识别色；
- 远方机会站：最明亮的暖金，但面积要小。

### 光的优先级

1. 中央车站暖光；
2. 当前可调查物件的小范围光；
3. 远方机会站；
4. 玩家；
5. 其他装饰光。

避免全场到处发光。

## 7. 3 分钟 Demo 路径

### 0:00–0:20 — 降落

玩家出现在中央换乘站。画面第一眼同时看到：左侧暗区、右侧暖区、前方雾、远处机会站。

看山只说一句：

> “这里没有人在等你回答。先看看这座城为什么变成这样。”

### 0:20–0:55 — 离场街区

用户被闪烁灯和纸张吸引，调查离职申请箱。

第一次完整体验：环境 → 看山解释 → 原回答 → 收观点卡。

### 0:55–1:30 — 缓冲街区

暖灯自然把玩家引向账本/工坊。用户获得第二张观点卡。

### 1:30–2:05 — 中央碰撞

回到中央站，把两张观点卡比较。

如果 AI 识别出共同条件，原本断开的桥/灯带亮起；如果缺信息，则雾加重。

这是演示高潮。

### 2:05–2:40 — 档案区

用户下到档案区，核对原回答证据，看到“观点不是结论”的产品价值。

### 2:40–3:00 — 远方

用户回望远方机会站，看山总结当前探索，而不是给最终答案。

## 8. 资产生产工作流

### 阶段 1：概念图

用生成图 / 手绘快速锁定：
- 构图；
- 光照；
- 区域情绪；
- 材质方向。

概念图不能直接作为最终背景。

### 阶段 2：拆资产

每个可交互物、建筑、地形独立生产，统一：
- 视角；
- 光源方向；
- 透视；
- 笔触/材质；
- 色温。

### 阶段 3：场景合成

先用低清资产完成可玩布局，再逐步换高质量资产，避免美术阻塞交互。

### 阶段 4：统一后处理

对所有资产施加同一套：
- 色彩 LUT / CSS filter；
- 轻颗粒；
- 雾；
- 光晕；
- 阴影；
- 边缘柔化。

这样即使素材来源不同，也尽量被压到同一视觉世界里。

---

## 9. 验收标准

视觉 v1 成功，不看“有多少资产”，只看以下五点：

1. 截图第一眼不像网页，也不像关卡编辑器；
2. 不看文字，也能区分左/中/右/下/远方五个空间情绪；
3. 用户自然知道哪里值得走近，但看不到明显“按钮”；
4. 场景在没有 NPC 的情况下仍然有故事；
5. 任何环境隐喻都能通过看山和原回答追溯回真实材料，而不是纯装饰。

如果这五点成立，才进入下一轮世界扩展。
