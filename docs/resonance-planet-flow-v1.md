# 观点星球主线 v1：碎片、刘看山与共鸣

> 当前实现分支：`resonance-scroll-v1`
>
> 产品层级保持不变：**知乎宇宙 → 问题星系 → 观点星球 → 火箭登陆 → 地表探索 → 火箭返航。** AI 推演观点继续使用空间中转站表达，不被普通星球语法覆盖。

## 1. 一颗星球 = 一条具体观点

地表不再把同一问题里的多个观点作为居民摆在一起。用户从问题星系选择的 `opinionId` 是整个地表的唯一核心观点。

问题负责组织观点；星球负责深入理解一个观点；跨观点比较与融合回到宇宙 / AI 中转站完成。

## 2. 寻知者的两阶段星系探索

寻知者第一次进入问题星系时，只看见较高可见度的主流 / 主要观点星球。

### 主星系阶段

玩家先选择一颗清晰的观点星球，登陆并完成核心认知碎片探索。

此时不会把低可见观点统一画成暗星；它们尚未进入当前可观测视野。

### 深空视野阶段

第一次完成初始可见观点的共鸣并返航后，系统获得新的认知参照系：

- 星系镜头拉远；
- 完整检索图重新进入可观测范围；
- 少量结构上更容易被忽略、但有真实来源的真人观点，出现在更远的外围空间；
- 它们初始表现为微弱信号，不展示完整标题；
- 寻知者真正聚焦后才显现为观点星球，并记录为“已发现”；
- AI 中转站永远不会被包装成“被埋藏的人类观点”。

“埋藏”只表示在**当前检索材料**中，因为支持度、来源热度、关系连接度或立场稀有度而更不显眼，不表示知乎平台主动压制。

## 3. 三块核心碎片

碎片替代旧的观点卡收集主线。碎片表示“玩家已经调查了这一部分”，不表示“玩家赞同它”。

### 主张碎片：观察

玩家走到代表核心主张的场景点。刘看山先问为什么这里会形成这样的环境，再明确当前材料能够确认的主张。

调查即获得主张碎片，因为这里验证的是“我已经看清它究竟在说什么”。

### 理由碎片：条件实验

玩家在条件闸机 / 控制台等装置中改变观点自己的成立前提：

- 每个条件可切换为“假设满足 / 假设不满足 / 尚未设置”；
- 地表路线亮度同步变化；
- 变化只表示观点在自身前提下的适用线索，不是现实预测；
- 至少操作一个条件后才能获得理由碎片；
- 如果材料没有提供结构化条件，明确展示“条件缺失”，允许把缺口本身记录为理解结果，绝不自动编造条件；
- 实验结束后，场景回到中性“已理解”状态，不保留某一组假设为真实结论。

### 依据碎片：溯源

玩家调查档案/痕迹，刘看山询问“一份材料最多能支撑多大的结论”。

有可追溯来源时，必须真正打开当前观点绑定的原文后才获得依据碎片；没有来源时，空档案位本身表示“目前无法核对”，可以把这一缺口记录下来。

## 4. 刘看山

刘看山是随寻知者探索的认知导航者，而不是普通观点居民。

- 地表场景中以小型同行角色跟随玩家；
- 对话只引用当前 `questionId + opinionId` 的材料；
- 三类触发分别为 `inspect-claim / inspect-reason / inspect-evidence`；
- 先提问，再解释；
- 缺失材料必须承认不知道；
- 不代替用户判断观点正确与否；
- 宇宙层负责提示“主星系 → 深空视野 → 认知遗迹已定位”的发现节奏。

## 5. 共鸣

三个核心碎片完成后进入独立 `resonance` 世界阶段，锁定移动。

### 卷

纵向画卷自上而下展开，整理：观点主张、为什么有人这样判断、玩家亲自看过的依据、仍然未知的部分。

### 句

画卷退场后，屏幕只留下统一产品原则：

> **共鸣意味着理解了观点，不意味着证明了观点。**

它不属于刘看山台词，没有卡片或系统边框，随后碎成光粒 / 雾迹消散。

### 变

文字消散后，世界才发生变化。所有主题都有晨曦，但主题拥有不同的主变化：

- Crossroads：`rebuild`，路径 / 关系重新显现；
- Archive：`reveal`，材料与结构变清晰；
- Theater：`illuminate`，局部被照亮；
- Forest：`bloom`，环境克制地生长；
- Machine：`awaken`，系统与装置苏醒。

雾不会统一全部消失。未知仍然保持未知。

## 6. 宇宙 ↔ 地表语义一致性

`getOpinionWorldTheme(opinion)` 使用两条语义轴：

1. **Semantic Grammar**：这条观点要以什么认知结构被理解；
2. **Biome**：这种思考处于怎样的认知 / 生存环境。

两者共同决定星球基础颜色、3D 轮廓与材质、气层/纹理/环、地表 motif/密度/雾/冷暖、碎片物件和共鸣变化。

AI 中转站使用独立节点类型，不套普通观点星球语法。

## 7. 返航后的探索痕迹

宇宙中的普通观点星球读取探索进度：

- 1/3、2/3 碎片：出现对应比例的部分光轨；
- 共鸣完成：形成完整探索环 + 第二圈回声环；
- 第一次主星共鸣同时解锁该问题星系的深空视野。

这些痕迹表示“我探索 / 理解过它”，不会改变星球的基础语义颜色，也不会暗示观点正确。

## 8. 当前验证

当前实现持续通过 GitHub Actions：

- `bun install --frozen-lockfile`
- `bun run lint`
- `bun run build`

后续重点是提高每类星球的实际环境构图、碎片交互差异和场景资产质量，而不是增加新的平行卡片系统。
